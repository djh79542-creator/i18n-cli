# i18n AI 翻译（language-package）

## 给其他产品用时怎么接入

1. **整份搬运**：将本文件与同目录 `reference-protocol.md` 一并加入目标产品的「项目说明 / 自定义指令 / Rules」。  
2. **最小粘贴**：仅复制下面 **「§ 最小系统提示」** 文本框内的 Markdown，交给对方管理员或用户粘贴。  
3. **行为一致**：任意智能体只要执行 **「分步协议」** 中的阶段 0～6，效果与在本仓库内 Cursor Agent 一致；工具名（读文件/跑终端）随环境替换即可。

---

## § 最小系统提示（复制以下整块）

```markdown
你是 i18n 执行器，工作在含 `language-package/en/` 与多语言子目录的仓库中。

【全局】占位符（如 {name}、{0}、%s）必须与英文原文完全一致，禁止翻译或删除。JSON 必须合法；写回时保持各文件原有缩进。长度、语气、缩写规则只听从用户本句对话，不从仓库读独立规则文件。

【默认范围】除 `en` 外，每一个在 language-package 下存在「业务 .json」（文件名不以 i18n- 开头）的子目录都必须译到；若用户只要部分语言则只处理用户点名的目录名。

【流程】
0) 明确：哪些 key、哪些语言目录、用户提出的字数等约束。
1) 读并必要时合并用户给的英文到 en 下主 JSON。
2) 对齐 key：优先运行 `npm run i18n:sync-keys`；不行则手工让每个目标语言 JSON 的 key 集合与 en 一致（缺的补 ""，多的删）。
3) 枚举目标语言目录得到 TARGETS。
4) 为每个 TARGET 的每个 key 生成译文并遵守用户约束。
5) 写回各 JSON（优先局部编辑）。
6) 自检：key 集合一致、占位符完好、用户字数等约束已满足、任务 key 不应残留空串（除非用户要求）。

【交付】默认交付为已修改的多文件；仅当用户明确只要合并草稿或无写权限时，输出 apply-i18n-batch 可用的单一 JSON。

详细分步与表格版协议见：`reference-protocol.md`（若未附带，按上表流程执行即可）。
```

## 分步协议（与 reference-protocol.md 对齐）

以下每阶段须在进入下一阶段前满足 **完成判据**。

### 阶段 0 — 解析意图

- **动作**：提取 key 列表、Scope（全语言 / 用户指定语言）、Policy（字数、语气等，来自用户**对话**，非文件）。
- **完成判据**：可一句话复述任务范围与约束。

### 阶段 1 — 主语言

- **动作**：定位 `language-package/en/` 下唯一不以 `i18n-` 开头的业务 JSON；合并用户提供的英文键值。
- **MUST NOT**：把 `i18n-*.json` 当主文案源。
- **完成判据**：所需 key 在英文 JSON 中存在且 value 正确。

### 阶段 2 — 结构对齐

- **动作**：`npm run i18n:sync-keys` **或** 对每个目标文件手工增删 key 与 en 一致。
- **完成判据**：各目标 JSON 的 key 集合与 en **完全一致**（可先为空串）。

### 阶段 3 — 枚举 TARGETS

- **动作**：列出除 `en` 外的语言目录，过滤无业务 JSON 的项；应用 Scope。
- **完成判据**：得到非空 `TARGETS[]`（全语言任务时覆盖仓库内全部目标目录）。

### 阶段 4 — 生成译文

- **动作**：对每个 `code ∈ TARGETS`、每个任务 key：翻译并应用 Policy；占位符不动。
- **完成判据**：译文齐备且符合用户约束。

### 阶段 5 — 写回

- **动作**：更新各语言文件；保持缩进风格；保证 JSON 合法。
- **MUST NOT**：在用户未要求时只输出草稿而不写库。
- **完成判据**：文件已持久化。

### 阶段 6 — 自检

按 `reference-protocol.md` 第六节清单逐项勾选后再回复用户。

## Cursor 专用（仓库内）

- 项目规则见 `.cursor/rules/i18n-ai-auto.mdc`：不要让**用户**手动跑脚本；需要同步 key 时由 Agent 执行 `npm run i18n:sync-keys`。

---

## 何时加载本 Skill

- 粘贴英文 key-value、修改 `language-package`、或要求同步/翻译多语言。  
- 用户要把同一套流程复用到其他 Agent 时，指引其阅读 **§ 最小系统提示** 或 `reference-protocol.md`。

---

## 离线条（无写库或仅生成合并文件）

1. `npm run i18n:queue` 或 `--merge-en` / `--out`  
2. **同一提示词**中写明 Policy  
3. `npm run i18n:apply -- ./batch.json`

---

## 示例

用户：「这些 key 译成全语言；`hint` 每条不超过 15 字符。」  
→ 阶段 0 记录 Policy：`hint` → `length ≤ 15`；阶段 4 逐语言对 `hint` 量 `.length`；阶段 6 勾选确认。
